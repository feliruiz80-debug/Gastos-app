# Control de Gastos

App simple para anotar ingresos, gastos y un tope mensual.

Los datos quedan en este navegador. No hace falta base de datos ni instalar nada.

## Qué se puede hacer

- Registrar ingresos y gastos.
- Elegir una categoría.
- Ver ingresos, gastos y saldo del mes.
- Ver el saldo disponible de todos los meses.
- Revisar el historial y borrar un movimiento.
- Definir un tope de gastos para el mes.

## Cómo abrirla

Abrí `index.html` en el navegador, o publicá esta carpeta en Vercel.
